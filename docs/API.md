# API Reference

Base URL locally: `http://localhost:5000/api`

Production base URL: `https://nexachain-backend-git-525634051724.asia-south1.run.app/api`

Unless stated otherwise, protected endpoints require:

```http
Authorization: Bearer <JWT>
Content-Type: application/json
```

Responses generally use `{ "success": true, "data": ... }`. Errors are handled centrally; exact validation/error payloads are generated by the middleware.

## Health

### `GET /health`

Public. Returns API health and server timestamp.

## Authentication

### `POST /auth/register`

Public.

```json
{
  "fullName": "Aarav Sharma",
  "email": "aarav@example.com",
  "mobileNumber": "+919876543210",
  "password": "ExamplePass123",
  "referralCode": "OPTIONALCODE"
}
```

`referralCode` is optional. Response: `201`, with `data.user`. Password is hashed; the password hash is excluded from normal user serialization.

### `POST /auth/login`

Public.

```json
{
  "email": "aarav@example.com",
  "password": "ExamplePass123"
}
```

Response includes `data.token` and `data.user`.

### `GET /auth/me`

Protected. Returns the authenticated user.

## Investments

### `POST /investments`

Protected.

```json
{
  "amount": 1000,
  "planName": "Demo Plan",
  "dailyRoiPercent": 0.5,
  "durationDays": 30
}
```

`planName`, `dailyRoiPercent`, and `durationDays` are optional; service defaults are applied. Amount limits are configured using `MIN_INVESTMENT` and `MAX_INVESTMENT`. The operation debits the user's existing demo wallet and creates referral income in a MongoDB transaction.

Response: `201`, `data.investment`.

### `GET /investments?page=1&limit=10&status=Active`

Protected. Lists only the current user's investments. `status` accepts `Active`, `Completed`, or `Cancelled`. Pagination is bounded to 100 items per page.

## Dashboard

### `GET /dashboard/summary`

Protected. Returns:
- `totalInvestments`
- `activeInvestments`
- `investmentCount`
- `totalRoiEarned`
- `totalLevelIncomeEarned`
- `dailyRoi`
- `walletBalance`
- `investmentStatusCounts`

### `GET /dashboard/histories?page=1&limit=10`

Protected. Returns paginated `roiHistory` and `levelIncomeHistory`, plus the latest 10 `walletTransactions`.

### `GET /dashboard/earnings-chart`

Protected. Returns daily ROI and level-income aggregates for the recent 30-day window.

## Referrals

### `GET /referrals/direct?page=1&limit=20`

Protected. Returns direct referrals for the authenticated user with pagination.

### `GET /referrals/tree`

Protected. Returns the nested referral tree rooted at the authenticated user.

### `GET /referrals/income?page=1&limit=20`

Protected. Returns paginated level-income records received by the authenticated user.

## Notes

- Object IDs and monetary serialization follow the Mongoose models.
- Protected routes derive the user identity from the JWT; clients cannot select another user's ID for these endpoints.
- The source code is the authority for validation and response details. Generate a Postman collection from the running API if a machine-importable collection is required.
